## Architecture & Selected Systems

### 01 / Secure Cloud Infrastructure on AWS
> Enterprise VPC network design isolating public workloads and sensitive services behind hardened bastion barriers.
* Engineered a multi-tier AWS architecture featuring distinct public and private subnets across multiple availability zones.
* Implemented secure traffic routing via NAT Gateways, Elastic Load Balancing, and tightly scoped IAM role-based policies.
* Built with a zero-trust mindset to defend against lateral movement and unauthorized surface exposure.

### 02 / Real-Time Distributed Communications Platform
> Low-latency bi-directional messaging pipeline built for persistent concurrency and fast state propagation.
* Developed reactive micro-backends leveraging Node.js, Express, and Socket.IO for sub-millisecond event broadcast.
* Integrated Redis pub/sub and in-memory caches to handle high-frequency active connections and presence tracking.
* Backed by schema-optimized MongoDB collections for resilient chat history storage.

### 03 / AI-Assisted Evaluation Platform
> Intelligent interview analysis engine with structured behavioral and technical assessment pipelines.
* Designed an asynchronous client using React, TypeScript, and Vite integrated with Gemini API.
* Implemented browser-level speech-to-text processing for real-time answer ingestion and automated rubric-based grading.
* Enforced identity verification and user session security via Clerk and Firebase datastores.
